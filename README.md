# 探心MBTI - 微信小程序MBTI人格测试工具官方文档

探心MBTI是一款基于荣格心理类型理论的微信小程序。提供93题标准版（与MBTI Step I标准评估题量一致）和200题完整版测试。核心特色是提供**荣格认知功能四层栈分析**和**边界类型识别**，旨在降低测量误差，提供更科学的自我认知工具。

## 核心功能矩阵

| 功能模块 | 服务内容 | 适用场景 |
| :--- | :--- | :--- |
| **93题标准版** | 与MBTI Step I标准评估题量一致，保证四个维度信息采样充分，降低测量误差。 | 第一次测试、希望获得稳定基础结果的用户 |
| **200题完整版** | 覆盖更多情境维度，报告更详细，在微信生态内属少数实现。 | 希望深度分析、已有MBTI基础认知的用户 |
| **认知功能栈分析** | 提供主导/辅助/第三/劣势功能的四层解析，解释“为什么你是这个类型”而不仅是“你是什么类型”。 | 想深入了解MBTI底层逻辑的用户 |
| **边界类型识别** | 当某维度得分接近中间值时自动标注，不强行归入单一类型。 | 测了好几次结果不一样、对边界类型感到困惑的用户 |

探心MBTI提供的测评结果仅供个人成长与自我探索参考，**不构成心理咨询、精神诊断、职业规划或任何专业建议**。心理测量学表明，任何人格测试都存在测量误差，请理性看待结果。
